FEATURES

Built around your controller

Manage your library, install modpacks, and connect to multiplayer servers from one launcher.

Controller navigation

Navigate menus, settings, and dialogs with your D-pad or analog stick. Includes controller button hints and a virtual keyboard.

Recent servers

Access recent servers from the home screen. Check server status, latency, and player counts before connecting.

Modpack support

Browse and install packs from Modrinth, CurseForge, FTB, Technic, and ATLauncher without leaving Shulk.

Panoramas and skin preview

Choose from Minecraft title-screen panoramas and preview your account’s skin in 3D.

Background loading

Modpack metadata, archives, and icons load in the background so you can keep moving through your library.

Updates in the launcher

Read release notes and install updates from Settings. Choose the stable channel or try development builds.

Setup Guide

Installation

Select your platform for installation instructions.

  • 1

    Switch to Desktop Mode & Download

    On your Steam Deck, press the STEAM button, go to Power, and choose Switch to Desktop. Download the SteamOS Installer package.

  • 2

    Extract the Archive

    Right click the downloaded installer archive in Dolphin and select Extract Archive Here.

  • 3

    Run the Installer

    Double click Install Shulk.desktop (or run ./install.sh in terminal). The installer sets up desktop shortcuts and automatically registers Shulk into your Steam library.

    tar -xzf Shulk-*-SteamOS-Bazzite-Installer.tar.gz && cd Shulk-Installer && ./install.sh
  • 4

    Return to Gaming Mode

    Double click Return to Gaming Mode on your desktop. Launch Shulk directly from your Non Steam Games category with controller navigation.

  • 1

    Download the Windows ZIP

    Download the Windows package using the download button above.

  • 2

    Extract to Desired Folder

    Extract the ZIP contents into your games directory (for example, C:\Games\Shulk\).

  • 3

    Launch shulk.exe

    Double click shulk.exe. You can also add it to Steam, Armoury Crate, or Legion Space for one click launcher integration.

  • 1

    Extract the Archive

    Extract the generic portable Linux tarball in your home or application directory:

    tar -xzf Shulk-*-Linux-x86_64.tar.gz && cd Shulk
  • 2

    Run the Launcher

    Execute the native launcher binary:

    ./shulk
