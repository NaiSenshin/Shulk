# Minecraft Xbox controller glyphs

These are the official Minecraft Bedrock Xbox UI textures published in Mojang's
`bedrock-samples` repository:

https://github.com/Mojang/bedrock-samples/tree/main/resource_pack/textures/ui

Shulk uses the face-button direction mapping defined by Minecraft: down = A,
right = B, left = X, and up = Y. The four colored letter pixels were changed to
white to provide a consistent monochrome hint bar; the original Minecraft pixel
shapes, shading, transparency, and 26 x 26 dimensions are otherwise unchanged.
The LB, RB, LT, and RT files are Mojang's unmodified Xbox bumper and trigger
textures from the same official texture set.
